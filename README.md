# Online-Store_Flea-Market
Онлайн магазин "Барахолка"

Интернет-магазина с полноценной серверной частью: регистрация и вход пользователей, каталог товаров, корзина и избранное, привязанные к аккаунту, оформление и история заказов в базе данных.

Это учебный проект — полноценный интернет-магазин с клиент-серверной архитектурой. Демонстрирует полный цикл работы с данными: от регистрации пользователя и выбора товаров до сохранения заказа в базе данных.

В проекте реализованы:
- Регистрация и вход по логину и паролю (с валидацией: возраст 14+, телефон из 11 цифр, уникальность логина и email)
- Каталог из 50+ товаров с поиском, фильтрацией по 9 категориям
- Карточка товара: галерея, характеристики, похожие товары
- Корзина и избранное, привязанные к аккаунту
- Оформление заказа с сохранением в базу данных
- Тёмная/светлая тема с сохранением выбора

У проекта классическая клиент-сервисная архитектура с разделением на слои:
- Контроллеры 
- Бизнес-логика (регистрация, вход)
- Работа с БД

Для разработки использовались:
- Java
- Spring Boot
- MySQL
- HTML5 (для внешней  части сайта)
